# 📄 Guía Técnica: Bot de Administración para Telegram en Debian 13

## Fase 1: Obtención de Credenciales en Telegram
1. **Crear el Bot:** Abre Telegram, busca **@BotFather**, envía `/newbot` y sigue las instrucciones. Guarda el **Token de API** (ej. `123456789:ABCdef...`).
2. **Obtener tu ID de Usuario:** Busca **@userinfobot** en Telegram e inicia con `/start`. Anota tu ID numérico (este será el `OWNER_ID`).
3. **Obtener el ID del Grupo:** Añade a tu nuevo bot a un grupo de Telegram. Envía cualquier mensaje en ese grupo. *Nota: El ID del grupo es un número negativo largo (ej. `-1001234567890`). Lo obtendremos en la Fase 6 si no lo tienes a mano.*

---

## Fase 2: Preparación del Entorno en Debian 13
Ejecuta estos comandos como tu usuario normal (`britojab`). Usaremos `/scripts/telegram-admin-bot` como directorio base.

```bash
# 1. Actualizar sistema e instalar dependencias
sudo apt update && sudo apt upgrade -y
sudo apt install python3 python3-pip python3-venv -y

# 2. Crear el directorio y asignar permisos correctos inmediatamente
sudo mkdir -p /scripts/telegram-admin-bot
sudo chown -R britojab:britojab /scripts/telegram-admin-bot

# 3. Entrar al directorio y crear el entorno virtual
cd /scripts/telegram-admin-bot
python3 -m venv venv

# 4. Activar el entorno e instalar la librería de Telegram
source venv/bin/activate
pip install python-telegram-bot
```

## Fase 3: Código del Bot (Completo y Corregido)
Crea el archivo principal del bot. Este código ya incluye las importaciones correctas (`MessageHandler`, `filters`) y la lógica de seguridad para ignorar a usuarios no autorizados.

```bash
nano bot.py
```

Copia y pega el siguiente código. **Asegúrate de reemplazar las 3 variables de configuración al inicio con tus datos reales.**

```python
import logging
import subprocess
from telegram import Update
# Importaciones corregidas y completas
from telegram.ext import Application, CommandHandler, ContextTypes, MessageHandler, filters

# --- CONFIGURACIÓN (REEMPLAZAR CON TUS DATOS) ---
BOT_TOKEN = "TU_TOKEN_AQUI"
OWNER_ID = 123456789          # Tu ID numérico de Telegram
ALLOWED_GROUP_ID = -1001234567890 # ID numérico de tu grupo (incluye el signo negativo)

# --- LOGGING ---
logging.basicConfig(
    format='%(asctime)s - %(name)s - %(levelname)s - %(message)s',
    level=logging.INFO
)
logger = logging.getLogger(__name__)

# --- SEGURIDAD Y AUTORIZACIÓN ---
def is_authorized(update: Update) -> bool:
    """Verifica si el usuario o el chat están autorizados."""
    user_id = update.effective_user.id
    chat_id = update.effective_chat.id
    chat_type = update.effective_chat.type

    # Si es mensaje directo, solo el propietario
    if chat_type == 'private':
        return user_id == OWNER_ID

    # Si es en grupo, debe ser el grupo autorizado
    return chat_id == ALLOWED_GROUP_ID

def run_command(command: list) -> str:
    """Ejecuta un comando predefinido de forma segura (sin shell=True)."""
    try:
        result = subprocess.run(command, capture_output=True, text=True, timeout=10)
        output = result.stdout if result.stdout else result.stderr
        # Truncar si la salida es muy larga para Telegram
        if len(output) > 4000:
            output = output[:3900] + "\n... [Salida truncada por límite de Telegram] ..."
        return output if output else "Comando ejecutado sin salida."
    except subprocess.TimeoutExpired:
        return "Error: El comando tardó demasiado en responder (Timeout > 10s)."
    except Exception as e:
        return f"Error al ejecutar el comando: {str(e)}"

# --- COMANDOS DEL BOT ---
async def start(update: Update, context: ContextTypes.DEFAULT_TYPE) -> None:
    if not is_authorized(update): return

    await update.message.reply_text(
        "🤖 *Bot de Administración*\n\n"
        "Comandos disponibles:\n"
        "/status - Estado de servicios críticos\n"
        "/network - Análisis de red y puertos\n"
        "/disk - Uso de disco",
        parse_mode='Markdown'
    )

async def status_cmd(update: Update, context: ContextTypes.DEFAULT_TYPE) -> None:
    if not is_authorized(update): return
    await update.message.reply_text("Consultando estado de servicios...")
    cmd = ["systemctl", "status", "ssh", "--no-pager"] # Ajusta 'ssh' por tus servicios
    output = run_command(cmd)
    await update.message.reply_text(f"```\n{output}\n```", parse_mode='Markdown')

async def network_cmd(update: Update, context: ContextTypes.DEFAULT_TYPE) -> None:
    if not is_authorized(update): return
    await update.message.reply_text("Analizando red...")
    cmd_ip = ["ip", "-br", "addr"]
    cmd_ss = ["ss", "-tuln"]
    await update.message.reply_text(f"*Interfaces:*\n```\n{run_command(cmd_ip)}\n```", parse_mode='Markdown')
    await update.message.reply_text(f"*Puertos escuchando:*\n```\n{run_command(cmd_ss)}\n```", parse_mode='Markdown')

async def disk_cmd(update: Update, context: ContextTypes.DEFAULT_TYPE) -> None:
    if not is_authorized(update): return
    await update.message.reply_text("Consultando uso de disco...")
    cmd = ["df", "-h"]
    output = run_command(cmd)
    await update.message.reply_text(f"```\n{output}\n```", parse_mode='Markdown')

async def unknown_cmd(update: Update, context: ContextTypes.DEFAULT_TYPE) -> None:
    if not is_authorized(update): return
    await update.message.reply_text("Comando no reconocido. Usa /start para ver las opciones.")

# --- MAIN ---
def main() -> None:
    application = Application.builder().token(BOT_TOKEN).build()

    # Registrar handlers
    application.add_handler(CommandHandler("start", start))
    application.add_handler(CommandHandler("status", status_cmd))
    application.add_handler(CommandHandler("network", network_cmd))
    application.add_handler(CommandHandler("disk", disk_cmd))

    # Handler para cualquier otro comando no registrado
    application.add_handler(MessageHandler(filters.COMMAND, unknown_cmd))

    logger.info("Bot iniciado. Esperando mensajes...")
    application.run_polling(allowed_updates=Update.ALL_TYPES)

if __name__ == '__main__':
    main()
```
Guarda el archivo (`Ctrl+O`, `Enter`) y sal (`Ctrl+X`).

## Fase 4: Configuración como Servicio de Systemd
Para que el bot se ejecute en segundo plano, inicie con el servidor y se recupere automáticamente si falla, crearemos un servicio.

*Nota: Aquí se usa explícitamente el usuario `britojab` y las rutas correctas sin duplicidades para evitar el error `217/USER` y `status=2`.*

```bash
sudo nano /etc/systemd/system/tg-admin-bot.service
```

Pega la siguiente configuración:

```ini
[Unit]
Description=Telegram Admin Bot
After=network.target

[Service]
User=britojab
Group=britojab
WorkingDirectory=/scripts/telegram-admin-bot
ExecStart=/scripts/telegram-admin-bot/venv/bin/python /scripts/telegram-admin-bot/bot.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```
Guarda y cierra el editor.

## Fase 5: Despliegue y Verificación
Aplica los cambios y inicia el servicio:

```bash
# 1. Recargar la configuración de systemd
sudo systemctl daemon-reload

# 2. Habilitar el bot para que inicie automáticamente al encender el servidor
sudo systemctl enable tg-admin-bot

# 3. Iniciar el bot
sudo systemctl start tg-admin-bot

# 4. Verificar que esté funcionando correctamente
sudo systemctl status tg-admin-bot
```
✅ **Éxito:** Debes ver `Active: active (running)` en color verde y un log que diga `Application started`.

## Fase 6: Pruebas y Obtención del ID del Grupo
1. Abre Telegram y envíale `/start` a tu bot desde tu cuenta personal. Debería responder.
2. Si aún no tienes el `ALLOWED_GROUP_ID` configurado en el código:
   - Añade el bot a tu grupo de Telegram.
   - Escribe `/start` en el grupo.
   - En tu servidor Debian, ejecuta: `sudo journalctl -u tg-admin-bot -n 10`
   - Verás una línea como: `Received message from user 123456789 in chat -1001234567890`.
   - Copia ese número negativo, edítalo en `bot.py` (`ALLOWED_GROUP_ID = -1001234567890`) y reinicia el servicio: `sudo systemctl restart tg-admin-bot`.

## ⚠️ Nota de Seguridad: Ejecución de Comandos con `sudo`
El bot se ejecuta con los permisos de `britojab`. Comandos como `df -h` o `ip addr` funcionarán perfectamente. Sin embargo, si en el futuro añades comandos que requieran privilegios de root (ej. `systemctl restart nginx`), el bot fallará por falta de permisos.

**Nunca cambies `User=root` en el servicio de systemd**, ya que es un riesgo crítico de seguridad. La forma correcta de hacerlo es otorgar permisos específicos a `britojab` sin contraseña:

1. Ejecuta `sudo visudo`
2. Añade esta línea al final (ejemplo para reiniciar servicios):
   ```text
   britojab ALL=(ALL) NOPASSWD: /bin/systemctl restart nginx, /bin/systemctl restart ssh
   ```
3. En tu código Python, modifica el comando para incluir `sudo`:
   ```python
   cmd = ["sudo", "systemctl", "restart", "nginx"]
   ```

Con esta configuración, tienes un sistema de automatización **robusto, seguro, con control de acceso estricto y tolerante a fallos**, listo para entornos corporativos.
